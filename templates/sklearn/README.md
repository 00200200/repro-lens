# ml_project

A runnable scikit-learn baseline generated by Repro Lens.

```bash
uv sync --locked
uv run python -m ml_project.train --config configs/baseline.toml --output runs/baseline
uv run pytest
```

The source tree is a Python package. `configs/baseline.toml` is the experiment
configuration; `pyproject.toml` configures dependencies and quality tools. The raw
synthetic dataset is a versioned fixture. `runs/` and `.repro-lens/` contain local
outputs. Use `notebooks/` for exploration; move reusable transformations into `src/`.

Install Repro Lens to check and replay this experiment:

```bash
uv tool install 'git+https://github.com/00200200/repro-lens.git@v0.2.0'
repro-lens check
repro-lens verify
git init
uv run pre-commit install
uv run pre-commit run --all-files
```

The package is distributed through GitHub releases and tagged source; it is not on PyPI.
For local development, invoke the CLI from its checkout with `uv run --project /path/to/repro-lens
repro-lens verify --root /path/to/this/project` (as one shell command).

See [reproduction instructions](docs/reproducing.md) and [dataset provenance](data/README.md).

The initial lockfile is generated for the template name. The generator substitutes
the selected package name in both metadata and lockfile. Run `uv lock --check` after
renaming or changing dependencies.
